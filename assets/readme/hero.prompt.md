## Prompt (for the family's image pipeline)

A clean technical ecosystem map on a soft near-white background, drawn as a
"control room" diagram of six labeled module nodes connected to a central
Family OS hub: Caty Agent Harness, Memory, Family Dev
Handbook, Sitter, **Self Growth Loop** (the hero of this image), and Persona
Growth Loop. The Self Growth Loop node is visually emphasized — larger, warm
accent color, subtle glow — while the other nodes stay muted gray-blue.
Inside or beside the emphasized node, a small circular five-step cycle reads:
sense → propose → trial → council → adopt, with a distinct hand/stamp icon
between "council" and "adopt" to signal explicit human approval before adoption.
(Issue #18 originally sketched this cycle as "observe → propose → review →
verify → adopt"; the implemented pipeline vocabulary — sense/propose/trial/
council/adopt, as used throughout the README — is deliberately preferred so the
image and the text teach the same five words.) Flat vector style,
thin lines, rounded rectangles, generous whitespace, no photographic
elements, no text other than the node labels and the five cycle words.

- Emphasize ONLY the Self Growth Loop node and the sense→propose→trial→council→adopt cycle.

- No version numbers, dates, URLs, or metrics baked into the image.
- Landscape, works at README width; also usable as the 1280×640 social preview crop.
